🧩 4 Pilar Computational Thinking

Penerapan pola pikir komputasional dalam menyelesaikan tantangan pemrograman Karel.

1. Dekomposisi Memecah Masalah Kompleks

Pecah misi labirin besar menjadi fungsi-fungsi kecil yang modular dan mudah dikelola:

function turn_right() {
  turn_left();
  turn_left();
  turn_left();
}
2. Pengenalan Pola Mendeteksi Keteraturan & Looping

Kenali pola berulang saat menyusuri lorong atau mengumpulkan bola:

while (front_is_clear()) {
  move();
  if (balls_present()) {
    take_ball();
  }
}
3. Abstraksi Fokus pada Logika Tingkat Tinggi

Gunakan sensor kondisi Karel tanpa harus menghitung koordinat piksel layar:

if (front_is_clear()) {
  move();
} else {
  turn_left();
}
4. Berpikir Algoritma Langkah Terstruktur (Wall Follower)

Rancang algoritma navigasi untuk menyelesaikan labirin secara otomatis:

function solve_maze() {
  while (no_balls_present()) {
    if (right_is_clear()) { turn_right(); move(); }
    else if (front_is_clear()) { move(); }
    else { turn_left(); }
  }
}
